# Conéctate Seguro

Landing Page educativa sobre seguridad en Internet.

## Estructura
- `index.html`: página principal.
- `style.css`: estilos, Flexbox, Box Model y responsive.
- `img/`: carpeta disponible para imágenes locales si fueran necesarias.

## GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `style.css` y la carpeta `img`.
3. Ve a **Settings → Pages**.
4. Selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)`.
6. Guarda y espera la publicación.
7. Abre la URL en una ventana de incógnito y comprueba que todo cargue correctamente.
